Lesson 4.1

A. Browser Output

Static vs Dynamic Web page

  • Static web page is a webpage delivered to the browser exactly as stored.
  • Dynamic web page displays different content and interacts with the users based on their action, preferences, etc.

Javascript

  • It is used to create dynamic, interactive user experiences, handling everything from UI rendering, and content loading to real-time updates, personalized feeds, video controls, and tracking user activity.
  • It is the most popular scripting language in the internet, supported by all major browsers.
  • It was developed by Brendan Eich of Netscape under the name Mocha, which was later renamed to LiveScript.
  • It was opened to Internet Explorer in 1996.
  • It is a trademark of the Oracle Corporation and is licensed for use to other entities like Mozilla Foundation
  • It is client-side, high-level scripting, interpreted and object-oriented.
    • Client-side - processed on the user's computer
    • High-level scripting - codes are written as close to english as possible, making it readable
    • Interpreted - codes are passed as source code then converted to machine codes
  • Case-sensitive
  • Semi-colons at the end if each statement are not required.
  • A script is a set of computer instructions that puts together existing components to accomplish a new related task.

What Javascript Can do

  • React to events (mouse clicks, pre-loading, etc)
  • Form Validation (Validate user input data)
  • Cookies (save and retrieve information from the user's computer)
  • Enhance a webpage

Features

  • Supports all structured programming syntax in C
  • Has dynamic typing
  • Can run locally in a web site
  • Can detect user actions
  • Can be combined with css to produce DHTML

Characteristics

  • Quick to download
  • Does not need extra tools (only needs text editor and web browser)
  • License-free
  • Supported by thriving community of developers

Disadvantages

  • Some browsers do not support it. Mobile phones do not run Javascript.
  • Any secret embedded in JS could be extracted by a determined adversary.
  • JS and DOM (Document Object Model) provide potential for malicious authors to deliver scripts to run on a client computer via web.
  • Web site authors cannot perfectly conceal javascript
  • Source codes that have been deliberately made hard to understand can be reverse engineered so your codes are still exposed to possible threat.

How to Start writing Javascript

put javascript codes inside <script></script>. Use the type attribute to define scripting language and version. To display something on the web page, use document.write.
