Lesson 4.2

A. Browser Output

Where to place JavaScript

  • Place the scripts inside the Head tag for function calls. Scripts here are pre-loaded (executed before any event are triggered).
  • Scripts placed in the body tag are executed when the page loads.
  • You can also link external javascript through the src attribute in the script tag. Just save a javascript file with the .js extension. This will help you control many html files at once.

You can add comments in javascript by placing them inside /* and */

JavaScript Guidelines

Knowing the guidelines will help keep you out of trouble and save time.

  • Case sensitive - in javaScript, lowercase letters are not the same as uppercase letters. For example, the variable MyHome is different from myHome.
  • White space - JavaScript ignores white space as long as it is withinthe line of the code. It is a good practice to use white spaces between expressions to make your codes easier to read
  • Breaking up of codes - You can break a code by using backslash ("\") but do not break the code in between commands or it will break.

B. What I have Learned

In this lesson, I learned where to put Javascript. I learned that you can put it in the head tag, the body tag, or in an external file. I also learned about the general guidelines we follow when writing JavaScript.
